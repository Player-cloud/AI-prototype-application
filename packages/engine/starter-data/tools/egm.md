# EGM (Elephant-Goldfish Model)
What: Google's free plugin (Apache 2.0, v0.1.1) where one AI drafts and several fresh-eyes AIs review a plan.
Use when: a big build (5+ features, or logins, payments, personal data), once per plan, before building.
Don't use when: small builds or every plan; Sonnet one pass found the same planted gaps for 1/77 of the cost.
Cost: about $1.45 and ~1M tokens per review (round 2, Opus). Drafting steps are interactive (one question at a time).
