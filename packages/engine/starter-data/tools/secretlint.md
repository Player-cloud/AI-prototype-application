# secretlint
What: free scanner (npm secretlint + recommended rules) that finds keys and passwords in files.
Use when: every build, and before every push.
Don't use when: n/a; it misses some formats (AWS docs-style keys, unusual tokens), so Haiku double-checks before Keep.
Cost: $0, under 1 second. Round 4: 4/6 planted, 0 false alarms.
