# axe-core (+ phone overflow script)
What: free open-source accessibility checker (MPL-2.0) run inside Playwright; plus a 1-line check that the phone page doesn't scroll sideways.
Use when: every build, automatically.
Don't use when: n/a; it can't judge whether a name or label actually makes sense (missed a menu button named only "☰").
Cost: $0, under 1 second. Round 3: 6/7 planted problems.
