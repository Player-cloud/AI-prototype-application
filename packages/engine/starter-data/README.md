# AI Prototype data folder

Made by AI Prototype. It holds what the app learns, on this computer. No keys or passwords ever go here.

- `ledger.md`: every tool, what it's for, its evidence and your rating
- `habits.md`: your habits and preferences
- `rules.md`: general tool rules (the app may edit these and says so)
- `tools/`: one card per tool
- `projects/<name>/`: each project's spec and results

It's a git folder, so every change can be undone. GitHub sync is off until you add a remote.
