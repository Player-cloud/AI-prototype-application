# R5: unsigned draft Windows installers (13 Nov 2026)

- **When and who:** 13 Nov 2026, 11:30–11:45 UK, Claude in the cloud. joshua merged PR #88.
- **Where:** GitHub Actions `windows-latest`, workflow `installer-draft`, run 43417577399, on commit `ac50ba3` (PR #88's head). Main is now at `aaa4d1d`.
- **How the app was started:** the installed copy was **not** opened as a window. Only its engine was started, by `scripts/smoke-bundle.mjs`.

## What was done

The job packs the engine, Node, pnpm and git (`toolchain.json`, SHA-256 checked), builds the NSIS `.exe` and the `.msi` **unsigned**, installs the `.exe` silently for the current user (no admin rights), checks the installed files, runs the pack check against the installed folder, uninstalls, and keeps the installers for 7 days as a workflow artifact. Nothing was signed, published or released.

## What this does not show

- That the app **window** opens or any screen works in the installed copy: no click-through yet.
- That a real build (paid, needs a key) runs from the installed tools.
- That the `.msi` installs: only the `.exe` was test-installed.
- What happens to the user's data folder, settings and keys on uninstall or upgrade.
- Signing: Windows will warn that the publisher is unknown (SmartScreen).
