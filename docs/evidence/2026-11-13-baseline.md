## Found while checking

- `node:sqlite` prints "ExperimentalWarning: SQLite is an experimental feature" on Node 22.23. It works, but the bundled Node version (stage R2) must be checked against it.
- The page server starts with `shell: true` on Windows and doesn't quote its arguments. That is fine for `pnpm`/`npm` today, but it will break once the app runs a bundled `node.exe` from a folder with spaces (stage R2).
